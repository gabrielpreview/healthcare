## Brand quick reference
- **Bring IT Green** `#7dbf41` — CTAs & highlights only
- **Dark Green** `#1a231f` — dark canvas
- **Near-black** `#0e1713` — text on light
- **Typeface** — Roboto only (Roboto Mono used sparingly for technical labels)
